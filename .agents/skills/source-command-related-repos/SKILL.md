# source-command-related-repos

Use this skill when the user asks to run the migrated source command `related-repos`.

## Command Template

The user will provide a number of repositories in the index (or to be added) which are related: they explore a common application for the Codex workspace model. They should be grouped. 

The user will either ask you to suggest a category name and description or provide one. 

Upon receiving the desired workflow, please update the README to reflect the new categorisation.
